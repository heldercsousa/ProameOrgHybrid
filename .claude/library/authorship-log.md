# Authorship & Approval Log

> **Purpose:** a record of who authored which rule, library file or governance decision in this
> repository's `.claude/` tree (and `CLAUDE.md`), and whether Helder reviewed and approved it.
> It is a human governance record, not agent guidance, so it is kept out of the always-loaded
> rules files.
>
> **Who writes it:** whoever changes a governed file records a row in the same commit. Claude Code
> rows name the commit and the reason; the approval column is filled only by Helder's own review
> (`CLAUDE.md § Amending These Rules`). An empty approval cell means "not yet reviewed".
>
> **Scope:** rules and library files under `.claude/`, `CLAUDE.md`, and any governance decision that
> changes how agents work in this repository. Feature specs are not logged here; they carry their own
> history in `Docs/Management/`.
