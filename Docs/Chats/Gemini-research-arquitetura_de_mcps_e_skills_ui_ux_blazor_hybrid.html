Alerta de Viés do Ecossistema

O Que Evitar no Blazor Hybrid

A maioria dos servidores MCP populares de UI foi desenhada para React e Next.js, gerando retrabalho constante de conversão para componentes .razor.

21st MCP (ex-Magic MCP) Baixo Retorno

Gera JSX/TSX + Tailwind com limite gratuito de 2 cópias/dia. Útil apenas para buscar logótipos SVG via SVGL.

shadcn/ui MCP Acoplado a React

Depende de Radix UI e primitivos React incompatíveis diretamente com o ciclo de vida Blazor.

Acúmulo de Skills de Estilo Conflito de Regras

Misturar Impeccable + UI/UX Pro Max + Taste Skill cria diretrizes contraditórias e infla o contexto inicial.

Regra de Ouro: Use 1 motor principal de direção + 1 memória de sistema + auditoria técnica.
Liberdade Estética Sem MD3

Estratégias de UI Compartilhada (Android, iOS e Web)

Como o Blazor Hybrid renderiza HTML e CSS padrão nas três plataformas e o Material Design 3 não é obrigatório, você pode adotar uma identidade de produto contemporânea sem aparência genérica de app Android antigo.

VIA 01 • MÁXIMA LIBERDADE Recomendada para Produto Próprio

CSS Moderno Proprietário ou Tailwind CSS

Extrai 100% do potencial da Impeccable e da Interface Design. Utiliza espaço de cor perceptualmente uniforme oklch(), misturas dinâmicas com color-mix() e tipografia fluida via clamp().

  • ✓ Zero herança visual rígida de Material Design
  • ✓ Adaptação nativa de densidade (bottom bar no mobile, sidebar no desktop)
  • ✓ Totalmente inspecionável por seletores CSS no Playwright e DevFlow
VIA 02 • PRODUTIVIDADE ENTERPRISE Apps Densos em Dados

Microsoft Fluent UI Blazor (Série v5)

Biblioteca oficial baseada em Web Components com estética limpa e moderna (não-MD3), ideal quando o projeto exige dezenas de data grids, seletores complexos e controles acessíveis prontos.

  • ✓ Integração nativa com .NET 10 e Blazor Hybrid
  • ✓ Estética contemporânea alinhada ao ecossistema Microsoft
  • ⚠ Atenção: Shadow DOM exige screenshots ou --caps=vision no Playwright MCP
Guia de Implantação Rápida

Workflow Operacional no Claude Code

Siga este fluxo enxuto para instalar apenas as ferramentas de alto impacto e padronizar o ciclo de design e validação no CLAUDE.md.

1. Instalação das Skills (Terminal)
npx impeccable install
npx skills add https://github.com/dammyjay93/interface-design --skill interface-design --agent claude-code -g
npx skills add https://github.com/vercel-labs/agent-skills --skill web-design-guidelines
2. Configuração dos MCPs (.mcp.json + CLI)
claude mcp add playwright npx @playwright/mcp@latest
npx ctx7 setup --claude

# Adicionar em .mcp.json:
# "maui-devflow": { "command": "maui", "args": ["devflow", "mcp"] }
