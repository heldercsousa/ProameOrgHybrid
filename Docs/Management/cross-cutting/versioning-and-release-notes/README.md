# Versioning and release notes

Semantic versions, release notes generated from conventional commits, and an in-app 'Novidades' page showing the current version and its changes.

## Release gate — vector logo (2026-11-27)
The first store release (Android/iOS) is blocked until the logo and symbol are redrawn as SVG. The current assets are rasterized from the working PNG, and the symbol crop is cut at the base. `MauiIcon` and `MauiSplashScreen` take that SVG. Source: `Docs/Benchmark/README.md § Gate de vetor`.
